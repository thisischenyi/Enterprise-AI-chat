  <action>
    Create backend/app/streaming/ package:

    buffer.py — SentenceBuffer class per D-STR01:
    - SENTENCE_END regex: split on period/exclamation/question followed by whitespace or newline, plus bare newlines. Avoid splitting on "Dr." or single-char abbreviations (period preceded by single uppercase letter).
    - add_token(token: str) -> list[str] — accumulates tokens, returns list of complete sentences when boundary detected
    - flush() -> str | None — returns remaining buffer content at stream end
    - full_response property — accumulates ALL tokens regardless of sentence splitting (for DB storage per D-STR03)

    service.py — StreamingChatService:
    - async method stream_response(message, model_id, conversation_id, user_id, db_session, pipeline, registry) -> AsyncGenerator yielding dicts
    - Performs input safety scan first (full-block per SAFE-03 — reuse pipeline.scan_input). If blocked, yield single error event and return.
    - Calls provider with stream=True, iterates tokens via httpx aiter_lines or openai SDK streaming
    - Feeds tokens into SentenceBuffer. For each complete sentence, calls pipeline._run_scanners (output scanners only) on that sentence.
    - Safe sentence -> yield {"event": "chunk", "data": {"content": sentence}}
    - Unsafe sentence -> yield {"event": "redacted", "data": {"category": risk_category, "label": redaction_label}} per D-STR02/D-STR08
    - Redaction labels: PII -> "[PII已过滤]", secrets -> "[机密信息已过滤]", policy -> "[策略违规已过滤]"
    - At stream end: flush buffer, scan final chunk, store full_response in DB Messages table (per D-STR03), yield {"event": "done", "data": {"conversation_id": id, "message_id": id}}
    - On provider error: yield {"event": "error", "data": {"message": "模型服务异常"}}

    chat_stream.py — POST /api/chat/stream endpoint per D-STR05:
    - FastAPI APIRouter, prefix="/api/chat"
    - Depends on get_current_user, get_db_session, SafetyPipeline, ProviderRegistry
    - Request body: ChatStreamRequest(message: str, model_id: str, conversation_id: str | None)
    - Returns EventSourceResponse from sse_starlette wrapping StreamingChatService.stream_response generator
    - Register router in main.py

    Audit events: emit audit event at stream end summarizing the overall decision (allow if no redactions, partial_redact if any redactions occurred). Use existing AuditRepository.
