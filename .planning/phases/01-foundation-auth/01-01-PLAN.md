| Boundary | Description |
|----------|-------------|
| Client -> API | Untrusted input crosses at auth endpoints (role parameter, mock tokens from frontend) |
| API -> Database | Auth middleware queries DB for session validation; fail-closed: invalid/missing session returns 401, never passes through |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | /api/auth/callback | mitigate | Validate mock token signature with itsdangerous TimedSerializer using SECRET_KEY; reject forged/modified tokens |
| T-01-02 | Spoofing | /api/auth/me | mitigate | Session token extracted from signed cookie; DB lookup validates authenticity; no token in response body |
| T-01-03 | Information Disclosure | Session cookie | mitigate | Cookie set with HttpOnly and Secure flags in production; SameSite=Strict for dev (relaxed for local dev) |
| T-01-04 | Elevation | Role enforcement | mitigate | get_admin_user dependency checks role == 'admin' for admin-only routes; employee role cannot access admin endpoints (403) |
| T-01-SC | Tampering | pip install | mitigate | Verify package legitimacy via pip/npm registry; ruff lint catches suspicious packages |
